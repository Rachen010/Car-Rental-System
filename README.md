# 🚗 Car Rental System

ระบบเช่ารถแบบ Console เขียนด้วย C++ (Project 02 วิชา Data Structures)
ใช้โครงสร้างข้อมูล **Binary Search Tree** และ **Linked List** ในการจัดการข้อมูลรถและประวัติการเช่าของลูกค้า

---

## โครงสร้างข้อมูลที่ใช้

| โครงสร้างข้อมูล | ใช้เก็บอะไร | Key | ไฟล์ |
|---|---|---|---|
| **Binary Search Tree** | ข้อมูลรถ | ทะเบียนรถ (plate) | `CarBST` |
| **Linked List** | ข้อมูลลูกค้า | รหัสลูกค้า (customer ID) | `CustomerList` |
| **Linked List** (ซ้อนในลูกค้าแต่ละคน) | ประวัติการเช่า | รหัสการเช่า (rental ID) | `CustomerList` |

### 4 Operations หลัก

| Operation | BST (รถ) | Linked List (ลูกค้า / ประวัติการเช่า) |
|---|---|---|
| **Create** | สร้างต้นไม้ว่าง | สร้างรายการว่าง |
| **Search** | ค้นหารถด้วยทะเบียน | ค้นหาลูกค้า / ค้นหาประวัติการเช่า |
| **Insert** | เพิ่มรถ (ทะเบียนห้ามซ้ำ) | เพิ่มลูกค้า / เพิ่มประวัติการเช่า |
| **Delete** | ลบรถ (รองรับ 3 กรณี: ไม่มีลูก, มีลูกเดียว, มีสองลูก) | ลบลูกค้า / ลบประวัติการเช่า |

---

## ฟีเจอร์

- เพิ่ม ค้นหา ลบรถ และแสดงรถทั้งหมดเรียงตามทะเบียน (inorder traversal)
- ลงทะเบียน ค้นหา ลบลูกค้า
- เช่ารถ: คำนวณราคาอัตโนมัติ (จำนวนวัน × ราคาต่อวัน) และเปลี่ยนสถานะรถเป็น `Rented`
- คืนรถ: เปลี่ยนสถานะประวัติเป็น `Returned` และรถกลับมา `Available`
- ดูประวัติการเช่าของลูกค้าแต่ละคน
- มีข้อมูลตัวอย่างโหลดให้อัตโนมัติเมื่อเปิดโปรแกรม

### กฎของระบบ
- ทะเบียนรถและรหัสลูกค้าห้ามซ้ำ
- รถที่กำลังถูกเช่าจะเช่าซ้ำหรือลบไม่ได้
- ลูกค้าที่ยังมีรถค้างคืนจะลบไม่ได้
- ประวัติการเช่าที่ยังไม่คืนรถจะลบไม่ได้
- ทะเบียนรถไม่สนตัวพิมพ์เล็ก/ใหญ่ (แปลงเป็นตัวพิมพ์ใหญ่ให้อัตโนมัติ)

## วิธีคอมไพล์และรัน

อยู่ในโฟลเดอร์ `Car-Rental-System` แล้วพิมพ์:

```
g++ -std=c++11 -Iinclude main.cpp src/CarBST.cpp src/CustomerList.cpp src/Menu.cpp src/Utils.cpp -o car_rental
```

จากนั้นรัน:

| Terminal | คำสั่ง |
|---|---|
| PowerShell | `.\car_rental.exe` |
| cmd | `car_rental.exe` |

> ถ้ามี `make` ติดตั้งอยู่ ใช้คำสั่ง `make` แทนได้

## เมนูโปรแกรม

```
[Cars - BST]
  1. Add car
  2. Search car
  3. Delete car
  4. Show all cars (sorted by plate)
[Customers - Linked List]
  5. Register customer
  6. Show customer rental history
  7. Delete customer
  8. Show all customers
[Rental]
  9. Rent a car
 10. Return a car
 11. Delete a rental record
  0. Exit
```

## ตัวอย่างลำดับการใช้งาน (สำหรับสาธิต)

1. เมนู `4` ดูรถทั้งหมด (เรียงตามทะเบียน)
2. เมนู `2` ค้นหารถ เช่น `1AB1234`
3. เมนู `5` ลงทะเบียนลูกค้าใหม่
4. เมนู `9` เช่ารถ แล้วเมนู `4` จะเห็นสถานะรถเป็น `Rented`
5. เมนู `6` ดูประวัติการเช่าของลูกค้า
6. เมนู `10` คืนรถ
7. เมนู `11` ลบประวัติการเช่า และเมนู `3` ลบรถ

## ความซับซ้อนของเวลา

| Operation | BST (เฉลี่ย) | BST (แย่สุด) | Linked List |
|---|---|---|---|
| Search | O(log n) | O(n) | O(n) |
| Insert | O(log n) | O(n) | O(n) |
| Delete | O(log n) | O(n) | O(n) |

> กรณีแย่สุดของ BST เกิดเมื่อเพิ่มข้อมูลที่เรียงลำดับอยู่แล้ว ทำให้ต้นไม้เอียงเป็นเส้นตรง

## การเก็บข้อมูลลงไฟล์ (Data persistence)

โปรแกรมบันทึกข้อมูลลงไฟล์ในโฟลเดอร์เดียวกับที่รันโปรแกรม และโหลดกลับมาทุกครั้งที่เปิด

- `cars.txt` — 1 บรรทัด = 1 คัน: `plate <TAB> brand <TAB> model <TAB> pricePerDay <TAB> available(1/0)`
- `customer.txt` — บรรทัด `C` = ลูกค้า (`C <TAB> id <TAB> name`) ตามด้วยบรรทัด `R` = ประวัติการเช่าของลูกค้าคนนั้น
  (`R <TAB> rentalId <TAB> plate <TAB> days <TAB> total <TAB> returned(1/0)`)

ถ้าไม่มีไฟล์ทั้งสอง (เปิดครั้งแรก) โปรแกรมจะสร้างจากข้อมูลตัวอย่างให้ และบันทึกใหม่ทุกครั้งหลังทำรายการในเมนู
อยากรีเซ็ตข้อมูล ให้ลบ `cars.txt` และ `customer.txt` แล้วเปิดโปรแกรมใหม่
